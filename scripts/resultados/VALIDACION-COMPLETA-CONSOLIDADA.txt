CAMBIOS APLICADOS EN src/ (compatibilidad FreeCAD 1.1.3)
================================================================================

1. src/tools/draft.ts
   - Booleanos en diccionarios de resultado: "closed": ${closed} → "closed": ${closed ? 'True' : 'False'}
   - Afecta: freecad_draft_wire, freecad_draft_bspline, freecad_draft_move,
             freecad_draft_rotate, freecad_draft_scale, freecad_draft_offset.

2. src/tools/sketcher.ts
   - freecad_add_sketch_bspline: "closed": ${closed} → "closed": ${closed ? 'True' : 'False'}
   - freecad_sketch_fillet: cambio de API. Schema ahora usa geoIndex/pointPos/radius
     y handler invoca sketch.fillet(geoId, pointPos, radius).

3. src/tools/part-design.ts
   - freecad_pad: Symmetric → Midplane; pad.Length → pad.Length.Value
   - freecad_pocket: pocket.Length → pocket.Length.Value
   - freecad_revolve: rev.Angle → rev.Angle.Value
   - freecad_loft: "solid": ${solid} → "solid": ${solid ? 'True' : 'False'}
   - freecad_partdesign_fillet: fillet.Radius → fillet.Radius.Value
   - freecad_partdesign_chamfer: cham.Size → cham.Size.Value
   - freecad_hole: attach del sketch al Tip del body (MapMode FlatFace + AttachmentSupport)
                  y uso de body.newObject para crear el Hole.

4. src/tools/advanced-operations.ts
   - freecad_extrude: "solid": ${solid} → "solid": ${solid ? 'True' : 'False'}
   - freecad_offset_3d: eliminado fill=True de makeOffsetShape.

5. src/tools/operations.ts
   - freecad_boolean_fuse: Shape1/Shape2 → Base/Tool
   - freecad_boolean_intersect: Shape1/Shape2 → Base/Tool
   - freecad_join_connect: Part::JoinConnect → BOPTools.JoinFeatures.makeConnect(name)
   - freecad_join_cutout: Part::JoinCutout → BOPTools.JoinFeatures.makeCutout(name)

6. src/tools/fem.ts
   - freecad_fem_mesh: mesh.Part = obj → mesh.Shape = obj
   - freecad_fem_solver: makeSolverCalculixCcxTools → makeSolverCalculiXCcxTools

7. src/tools/surface.ts
   - freecad_surface_filling: agregado import Surface; BoundEdges → BoundaryEdges
   - freecad_surface_geomfill: agregado import Surface; BoundEdges → BoundaryList

8. src/tools/bim.ts
   - freecad_arch_stairs: Arch.makeStairs(N) → Arch.makeStairs() + stairs.NumberOfSteps = N
   - freecad_export_ifc: import importIFC → from nativeifc import ifc_export; exportIFC()

9. src/tools/techdraw.ts
   - freecad_techdraw_export_svg: TechDraw.writeSVGPage → TechDraw.viewPartAsSvg + write file
   - Usa page.Views en vez de page.Group.

   - import_iges: requiere ImportGui (GUI). 1 tool afectada.
   - export_ifc, fem_mesh, fem_solver: operaciones pesadas que timeoutean en headless.
   - bim wall: ocasionalmente timeout en runner aislado.

   abierto y el macro freecad_server.FCMacro ejecutándose.

   usan APIs existentes en FreeCAD 1.1.3.
