[FAIL] [API-ROTA] freecad_arch_stairs
  Error: "Type must be App.DocumentObject or None, not int"
  Causa: Arch.makeStairs() en FreeCAD 1.1.3 NO acepta un int como primer arg.
         La API cambió: makeStairs() se llama sin args y se setea stairs.NumberOfSteps después.
  Fix: cambiar `Arch.makeStairs(${numberOfSteps})` → `Arch.makeStairs()` y luego
       `stairs.NumberOfSteps = ${numberOfSteps}` (esta propiedad ya existe).
  Archivo: src/tools/bim.ts línea 341.

[FAIL] [requiereWorkbench/modulo] freecad_export_ifc
  Error: "No module named 'importIFC'"
  Causa: El módulo `importIFC` fue eliminado en FreeCAD 1.1.3. El IFC export
         ahora vive en `nativeifc.ifc_export.exportIFC()`.
  Fix: reemplazar `import importIFC; importIFC.export(...)` con:
       `from nativeifc import ifc_export; ifc_export.exportIFC(objs, path)`
  Archivo: src/tools/bim.ts línea 355.

[FAIL] [API-ROTA] freecad_fem_mesh
  Error: "'FeaturePython' object has no attribute 'Part'"
  Causa: El mesh object de ObjectsFem.makeMeshGmsh() tiene propiedad `Shape`,
         NO `Part`. El handler hace `mesh.Part = obj` pero debe ser `mesh.Shape = obj`.
  Fix: cambiar `mesh.Part = obj` → `mesh.Shape = obj.Shape` (o `mesh.Shape = obj`).
  Archivo: src/tools/fem.ts línea 295.

[FAIL] [API-ROTA] freecad_fem_solver
  Error: "module 'ObjectsFem' has no attribute 'makeSolverCalculixCcxTools'"
  Causa: El nombre correcto en FreeCAD 1.1.3 es `makeSolverCalculiXCcxTools`
         (X mayúscula en CalculiX). El handler usa `makeSolverCalculixCcxTools`.
  Fix: cambiar `makeSolverCalculixCcxTools` → `makeSolverCalculiXCcxTools`.
  Archivo: src/tools/fem.ts línea 330.
  Nota: el solver run (CalculiX) requiere binario ccx externo; si se pasa run=true
        y ccx no está instalado, fallará por dependencia externa (no por bug).

[FAIL] [API-ROTA] freecad_surface_filling
  Error: "'Part.Feature' object has no attribute 'BoundEdges'"
  Causa: El handler no importa el módulo `Surface`, por lo que el tipo
         `Surface::Filling` no se registra y addObject crea un Part.Feature
         genérico. Además, la propiedad correcta es `BoundaryEdges`, no `BoundEdges`.
  Fix: 1) agregar `import Surface` antes de addObject.
       2) cambiar `fill.BoundEdges` → `fill.BoundaryEdges`.
  Archivo: src/tools/surface.ts líneas 107-116.

[FAIL] [API-ROTA] freecad_surface_geomfill
  Error: "'Part.Feature' object has no attribute 'BoundEdges'"
  Causa: Misma causa que filling. El tipo `Surface::GeomFillSurface` no se registra
         sin importar Surface. La propiedad correcta es `BoundaryList`, no `BoundEdges`.
  Fix: 1) agregar `import Surface`.
       2) cambiar `gf.BoundEdges` → `gf.BoundaryList`.
  Archivo: src/tools/surface.ts líneas 119-129.
